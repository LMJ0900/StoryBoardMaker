# 노션 리퀘스트 문서화 규칙

사용자의 리퀘스트(요청) 작업이 끝나면, Notion의 "스토리 보드메이커 관련" 페이지에 아래 구조로 작업 내용을 정리한다.

- 페이지: [스토리 보드메이커 관련](https://app.notion.com/p/3c2702465db980d6b643cf3b4ac9daee)

## 구조

1. **리퀘스트 토글** — 리퀘스트(요청) 하나당 페이지 최상위에 토글을 하나 생성한다.
   - 제목: `[YYYY-MM-DD] 리퀘스트 요약`
   - 내용: 요청 배경/목적, 수행한 작업 요약, 결과물(PR 링크 등)
2. **커밋 토글** — 리퀘스트 토글 하위에, 해당 리퀘스트에서 발생한 커밋마다 하위 토글을 생성한다.
   - 제목: 커밋 메시지 (Prefix 포함)
   - 내용: 커밋 해시, 변경 파일 요약, 변경 이유

## 예시

```
[2026-08-20] 초기 프로젝트 세팅 및 PR 생성 (토글)
├─ 요청 배경, 작업 요약, PR 링크
├─ [Docs] 스토리보드 서비스 기획 문서 추가 (하위 토글)
│  └─ 커밋 해시, 변경 파일, 변경 이유
└─ [chore] Next.js/NestJS 스캐폴딩 (하위 토글)
   └─ 커밋 해시, 변경 파일, 변경 이유
```

커밋 Prefix 규칙은 [commit-convention.md](./commit-convention.md) 참고.
